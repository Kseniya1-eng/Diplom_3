## Задание 3: Автотесты для веб-приложения Stellar Burgers (UI)

### Что протестировано

**Основная функциональность:**
- переход по клику на «Конструктор»;
- переход по клику на раздел «Лента заказов»;
- клик на ингредиент открывает всплывающее окно с деталями;
- всплывающее окно закрывается кликом по крестику;
- при добавлении ингредиента в заказ счётчик этого ингредиента увеличивается.

**Раздел «Лента заказов»:**
- при создании нового заказа счётчик «Выполнено за всё время» увеличивается;
- при создании нового заказа счётчик «Выполнено за сегодня» увеличивается;
- после оформления заказа его номер появляется в разделе «В работе».

### Паттерн Page Object

Элементы страниц описаны с помощью паттерна Page Object:

- `pages/base_page.py` - базовый класс с общими методами;
- `pages/constructor_page.py` - конструктор бургера;
- `pages/login_page.py` - страница входа;
- `pages/feed_page.py` - лента заказов.

Локаторы вынесены в `locators`.

### Браузеры

Тесты поддерживают Google Chrome и Mozilla Firefox. Браузер выбирается
параметром `--browser`:

> `$ pytest --browser=chrome`
>
> `$ pytest --browser=firefox`

### Запуск

**Установка зависимостей**

> `$ pip install -r requirements.txt`

**Запуск автотестов с формированием результатов для Allure**

> `$ pytest --alluredir=allure-results`

**Формирование и открытие Allure-отчёта**

> `$ allure generate allure-results -o allure-report --clean`
>
> `$ allure open allure-report`

### Примечания

- Для подготовки данных (создание и удаление тестового пользователя)
  используется API Stellar Burgers, сами сценарии выполняются через UI.
- Для добавления ингредиентов в заказ используется JS-эмуляция
  drag&drop — она стабильно работает и в Chrome, и в Firefox.
